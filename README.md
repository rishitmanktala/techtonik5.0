# ⚡ Techtonik 5.0 — Broken to Brilliant

**Official website for Techtonik 5.0** — a tech event organized by Suncity School.

A stunning, cinematic single-page website with a dark theme, gold accents, custom cursor, and smooth scroll animations.

---

## ✨ Features

- 🎨 **Cinematic Design** — Deep black/navy palette with gold and teal accent gradients
- ✨ **Custom Cursor** — Animated dot + ring cursor that reacts to hover states
- 📜 **Event Gallery** — Photo gallery from the event with lightbox-style images
- 📱 **Fully Responsive** — Optimized for all screen sizes
- 🎭 **Scroll Animations** — Fade-in effects triggered on scroll
- ♿ **Accessible** — Skip-to-content link and focus-visible styles

---

## 🚀 Getting Started

```bash
git clone https://github.com/rishitmanktala/techtonik5.0.git
cd techtonik5.0
# Open index.html in a browser
```
